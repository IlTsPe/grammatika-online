# Грамматика онлайн

Тренажер грамматики английского языка для уровней A1–C2. Правила написаны простым языком, к каждой теме есть упражнения с проверкой.

Сайт: https://iltspe.github.io/grammatika-online/

![Грамматика онлайн](favicon/og-image.png)

## Что есть в тренажере

- **20 разделов и 84 темы** — от артиклей и времен до Complex Object, Complex Subject и инверсии. Разделы идут по порядку: упражнения каждой темы опираются только на уже пройденный материал.
- **339 упражнений** пяти видов: вписать слово в пропуск, выбрать вариант, заполнить пропуски в связном тексте, перевести предложение и собрать фразу на слух.
- **Уровни A1–C2** у каждой темы и фильтр по уровню в меню.
- **Проверка ответов** засчитывает сокращенную и полную форму (*I'm* и *I am*, *don't* и *do not*) и несколько верных вариантов перевода.
- **Прогресс по темам**, «Работа над ошибками», избранное и заметки к темам.
- **Сохранение прогресса в файл** и загрузка его на другом устройстве.
- **Работа без интернета** и установка на телефон или компьютер как приложения.
- **Светлая и темная темы**, поиск по темам.

## Как устроен сайт

Сайт статический: HTML, CSS и JavaScript без фреймворков и без сборки. Его можно открыть с любого статического хостинга, сейчас он размещен на GitHub Pages.

| Путь | Что там |
|---|---|
| `index.html` | Каркас сайта: шапка, меню, область страницы |
| `style.css` | Все стили, светлая и темная темы |
| `data/` | Содержимое тренажера: по файлу на раздел (`01-articles.js` … `20-extra.js`) — правила и упражнения |
| `js/` | Логика: переходы между страницами, упражнения и проверка, «На слух», меню, прогресс, сохранение в файл, офлайн-режим, страницы «Информации» |
| `audio/` | Озвучка упражнений «На слух»: по три mp3 на тему и их список `index.js` |
| `fonts/` | Шрифты сайта (Unbounded, Golos Text, Literata, JetBrains Mono), хранятся здесь, а не загружаются с Google Fonts |
| `favicon/` | Значок вкладки, иконки приложения и картинка-превью ссылки |
| `articles/`, `tenses/` … `about/` | Копии `index.html` для чистых адресов вида `/articles/art-a-an`. В каждой копии уже есть текст страницы — так ее видят поисковики |
| `404.html`, `notes.html`, `mistakes.html` | Страница «не найдено» и личные страницы «Заметки» и «Ошибки» (закрыты от индексации) |
| `sw.js`, `manifest.webmanifest` | Работа без интернета и установка как приложения |
| `sitemap.xml` | Карта сайта для поисковиков |

Копии страниц, карта сайта, озвучка и картинка-превью собираются скриптами, которые лежат отдельно от репозитория. Вручную копии не правятся: после изменений в `index.html` или `data/` их пересобирают заново.

## Как запустить у себя

Подойдет любой статический сервер. Например, из папки репозитория:

```
python -m http.server 8000
```

и открыть http://localhost:8000/. Внутри сайта все переходы работают; прямые адреса без `.html` (например, `/articles/art-a-an`) открывает только GitHub Pages.

## Данные пользователя

Прогресс, ответы, избранное, заметки и настройки хранятся только в браузере пользователя (localStorage) и никуда не передаются. Сам тренажер файлы cookie не использует. Статистика посещений (Яндекс Метрика) включается только после согласия в плашке о cookie. Подробно — на страницах «Как сохранить прогресс» и «Файлы cookie» в разделе «Информация» на сайте.
