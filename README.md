# Грамматика онлайн

Сайт: https://iltspe.github.io/grammatika-online/

![Грамматика онлайн](favicon/og-image.png)

## Что есть в тренажере

Тренажер включает 20 разделов и 84 темы: от базовых (артикли, времена) до сложных конструкций (Complex Object, Complex Subject, инверсия). Материал выстроен последовательно: упражнения в каждой теме используют только уже изученные правила.

Доступно 339 упражнений пяти типов:

- вставить слово в пропуск;
- выбрать правильный вариант;
- заполнить пропуски в связном тексте;
- перевести предложение;
- составить фразу по аудио.

Система проверки учитывает разные варианты ответов: принимает и сокращенные, и полные формы (например, *I'm* и *I am*, *don't* и *do not*), а также несколько корректных вариантов перевода.

Функционал платформы:

- отслеживание и сохранение прогресса;
- экспорт прогресса в файл и импорт на другом устройстве;
- раздел «Работа над ошибками»;
- возможность добавлять темы в «Избранное»;
- создавать свои личные заметки.

Приложение работает без подключения к интернету, его можно установить на телефон или компьютер в виде приложения (подробнее «Инфо» → «Работа без интернета»).

Дополнительные удобства:

- в меню имеется фильтр по уровню сложности;
- выбор светлой или темной темы оформления, поиск по темам.

## Данные пользователя

Прогресс, ответы, избранное, заметки и настройки хранятся только в браузере пользователя (localStorage) и никуда не передаются. Сам тренажер файлы cookie не использует. Статистика посещений (Яндекс Метрика) включается только после согласия в плашке о cookie. Подробно — на страницах «Как сохранить прогресс» и «Файлы cookie» в разделе «Информация» на сайте.
